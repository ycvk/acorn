# ADR 0018 早安卡把今日关注的事讲透

测试机上 2026-11-06 到 11-10，owner 每天都在用，8 条消息里 4 条是在早安卡上点事件，4 条是随手求证一件新闻。早安卡每天约 10 条，每条一句话，整份 15 秒写完；卡片上每条只显示一行标题，摘要要进 Briefings 对话才看得到。想知道一件事的来龙去脉只能点标题，后端新建对话现场生成，从点下去到出第一个字要 14 到 61 秒。「持续跟进」「多报这类」「少报这类」在长按菜单里，owner 没有用过。

## 决策

### 今日关注的事各写一篇短文

早安卡照旧挑约 10 件事并选出今日关注。调度器记下一份早安卡挑了什么之后，为每件今日关注的事在它的对话里起一个 run 写短文；这件事还没有对话时用早安卡写的标题新建一个。run 的输入是一条 wake 消息 `[piece <日期>] <标题>`，模型在它旁边看到这是早安卡的今日关注，以及事件的板块、标题、摘要、最新进展和条目，都标为外部数据。

短文先读原文、再搜其他报道，按四段写：发生了什么、背景、各方说法、接下来看什么，每个说法写明出自谁，未证实的写明未证实，最后列出用到的链接。这件事的对话里已有内容时，run 看得到它，写清相对上次新在哪里。

这些 run 属于 owner 开启的早安卡，不算自主唤醒，不占唤醒额度；用的是对话模型。

### 推送等短文写完

早安卡在 owner 设定的时间之前 5 分钟开始写。它的推送在短文的 run 都结束后发出，最晚等到早安卡写完后 5 分钟，且不早于 owner 设定的时间。短文的 run 失败、被停止或等审批时，这件事在卡片上没有短文，推送照发。

### 此刻页与阅读页

简报卡片把今日关注的事各列成一张卡：标题、早安卡写的那句话、来源，以及短文的状态。其余的事列在「快讯」下，每条带那句话和来源。

点一件事进入它的阅读页。有短文时直接显示短文；没有时显示早安卡写的那句话。阅读页上有原文链接、「持续跟进」「多报这类」「少报这类」三个按钮，以及进入这件事对话的入口：有对话时打开它接着问，没有时让 Acorn 展开讲讲。长按菜单随之取消。

只有短文、owner 没有说过话的对话不列在对话页里；owner 在里面发过消息后照常列出。

### 分栏按事件内容

早安卡按事件的内容把它归到板块，不看它来自哪个信源的板块。

### 接口与存储

`news_story_messages` 的 `intent` 增加 `piece`，那一行的消息是短文 run 的 wake 消息。`briefing_picks` 增加 `pieces_at` 与 `pushed_at`：短文的 run 何时起、推送何时发；两者都以条件更新认领，一份早安卡只起一次短文、只推一次。

`NowBriefingStory` 增加 `sources`（这件事各条目的信源名）与 `piece`：`status` 为 `writing`、`ready` 或 `failed`，`ready` 时带短文全文 `body` 与写完的时间。一份早安卡的短文是它写完之后为同一件事起的最新一个短文 run。

### 边界变化

`/v1` 合同的 `NowBriefingStory` 多两个字段，`GET /v1/threads` 不再列出只有短文的对话。早安卡的开始时间比设置早 5 分钟，推送从「记下挑了什么就发」改为等短文。App 的简报卡片与事件的入口整体更换，新增阅读页。

## 分期

| 期 | 内容 | 验收 |
|---|---|---|
| P1 | `piece` 消息与短文 run；`pieces_at`、`pushed_at` 与推送时机；早安卡提前开始；`NowBriefingStory` 的两个字段；对话列表的过滤；早安卡技能的分栏写法 | 测试机上一份早安卡写完后，今日关注的每件事各有一个对话和一篇四段的短文，带至少两个不同来源的链接；推送在短文写完后、设定时间到了才发出，且只发一次；`/v1/now` 里这几件事的 `piece.status` 为 `ready` 并带全文；这些对话不在对话列表里，在其中发一条消息后出现 |
| P2 | App 的简报卡片、快讯与阅读页 | owner 在手机上看到三张卡与快讯，每条有那句话和来源；点一张卡立即看到短文，点原文链接打开来源；在阅读页标多报、少报后卡片上出现标记；点「接着问」进入这件事的对话，短文在里面；点一条快讯看到那句话与「展开讲讲」 |

## 代价

- 每天早上多三个带检索的 run，用的是对话模型的额度。
- 短文的对话没人看也一直留着，连同它的 run 与抓取的网页。
- 早安卡比设定时间早 5 分钟截稿，这 5 分钟里的新闻进第二天的早安卡。
- 快讯点「展开讲讲」仍是现场生成。
- 短文 run 需要审批时停在等待里，那件事当天没有短文。
