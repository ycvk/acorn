# ADR 0015 owner 对早安卡新闻的反馈

ADR 0013 的新闻编辑部里，事件的 1–5 分和早安卡挑哪些都由模型独自决定。2026-10-24 的早安卡没选打 5 分的「普京提议中美俄三方会谈」，选了打 4 分的「菲律宾央行加息」；这样挑合不合 owner 的意，Acorn 无从得知。夜思每周评估新闻源时看的每天条数、平均分、高分件数、跨源重合和"被早安卡采用"，也全是模型产出的数字，其中"被早安卡采用"靠在早安卡正文里查找条目链接算出。

owner 看早安卡只看推送里今日关注的三行，再扫一眼此刻页的简报卡片，不进对话读全文，也不点原文链接，点开了哪些原文测不出兴趣。owner 愿意做两件事：对某一条标"多报这类"或"少报这类"；在对话里直接说"AI 融资别报了"。2026-10-22 以来 owner 没有就早安卡说过话。

## 决策

### 记下早安卡挑中的事件

早安卡 run 结束后，后端读回复里的新闻板块：每条编号条目的链接属于某个候选事件的条目，据此按 run 记下挑中的事件、板块、顺序、标题和那一句话。今日关注每行以对应条目的编号开头，那几件标为今日关注。链接对不上候选事件的条目留在对话里，不上卡片，条数写进下一份早安卡的 System health。

夜思统计"被早安卡采用"改读这份记录。

### 卡片上的反馈

此刻页的简报卡片按板块列出挑中的事件，每件一行标题，标出今日关注的三件。长按一件弹出「多报这类」「少报这类」，选过的显示标记，再选一次取消。反馈只记录，不起 run，下一份早安卡开始用它。

每个事件至多一条反馈，后选的覆盖先选的。反馈记下时间、设备，以及事件当时的板块、标题和来源，事件过期后照样可读；反馈保留 30 天。反馈不登记为记忆来源，持久的变化落在板块偏好上。

接口是 `PUT /v1/news/stories/{story_id}/reaction`（`more` 或 `less`）与同路径的 `DELETE`；`NowBriefing` 增加挑中事件的列表，每件带当前的反馈。

### 挑选

早安卡的输入在每个板块下附上 owner 近 30 天在这个板块的反馈：事件标题、多报或少报、日期。早安卡技能先看反馈再看五个标准：与"多报这类"同类的事件优先入选，与"少报这类"同类的事件没有重大进展就不报。后台打分不看反馈，照旧按大众重要性与板块偏好。

### 板块偏好

owner 在对话里说"AI 融资别报了"时，agent 用 `news_sections` 改写那个板块的偏好，直接生效。

夜思每周的新闻回顾带上各板块这一周的反馈。同一板块一周里有两次以上反馈指向同一类事件时，夜思用 `news_sections` 提出改写偏好，理由列出这几次反馈。Acorn 自己醒来的 run（夜思、游思、早安卡与约定）里改动板块的 `news_sections` 调用等 owner 批准，审批详情给出改前改后的偏好；`approval.allow` 可以放开它。

### 新闻源评审

夜思看到的每个新闻源的统计增加三项：近 7 天挑中的事件里含它条目的件数，其中进今日关注的件数，owner 标多报与少报的件数。没有反馈的事件不计入正面或负面。

### 边界变化

SQLite 增加早安卡挑中的事件与 owner 的反馈两张表。`/v1` 合同增加反馈端点与 `NowBriefing` 的挑中事件。早安卡技能的今日关注格式改为以编号开头。`news_sections` 在 Acorn 自己醒来的 run 里等 owner 批准。本决定扩展 ADR 0013 的早安卡精选与夜思的新闻源评审。

## 分期

| 期 | 内容 | 验收 |
|---|---|---|
| F1 | 记下挑中的事件；反馈的表与接口；挑选输入附反馈；Acorn 自己醒来的 run 里 `news_sections` 等批准；夜思的偏好建议与新增的源统计；技能的今日关注格式 | 测试机上一份早安卡结束后，记下的事件与今日关注和正文一致；经接口给「菲律宾央行加息」标少报，下一份早安卡的输入在国际与财经板块下列出这条反馈，挑选里没有同类的小国央行利率消息；夜思周回顾列出各源的入选、今日关注与反馈件数，就有两次同向反馈的板块提出改写偏好，owner 批准后偏好改变；owner 在对话里让 agent 改偏好，不经审批直接生效 |
| F2 | 此刻页卡片列出挑中的事件，长按反馈 | owner 在手机上长按一件选「少报这类」，标记出现，后端记下；再选一次标记消失，后端删除 |

## 代价

- 反馈稀疏。owner 多数早上不标，挑选与评审在很长时间里仍以模型的分数为主。
- "这类"由模型理解，一次「少报这类」可能被理解得太宽或太窄，只能从之后的早安卡看出来；改写偏好时 owner 在审批里看得到原文。
- 挑中的事件靠解析回复得到，模型不按格式写或链接写错时，那几条没有反馈入口。
- 对话里的偏好改动不经审批，agent 把"这类"理解偏了时，owner 要从之后的早安卡里发现，再在对话里纠正。
- 卡片变长：约 10 件事件各占一行，个人部分的预览排到后面。
- 只有挑中的事件能反馈。没进早安卡的事件，例如「普京提议中美俄三方会谈」，owner 看不到，也就无从反馈。
